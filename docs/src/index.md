# SaddlepointExpansions.jl

Saddlepoint expansions of any order for tail probabilities and densities of random vectors,
from the cumulant generating function alone.

The package implements the expansions of

> S. A. Broda and R. Kan, *Uniform saddlepoint expansions for multivariate tail probabilities*,

for the orthant probability ``P(X \ge x)`` (componentwise) of a random vector ``X`` in any
dimension, for its density, and for the density and distribution function of a ratio, together
with the classical univariate expansions (Daniels; Hauschildt and Robinson) as the case
``d = 1``. The first-order term of the multivariate tail expansion is the approximation of
Kolassa (2003); the terms of orders two and higher are new, and their relative error is
``O(n^{-M})`` at order ``M``, uniformly on compact sets of saddlepoints in the closed positive
orthant.

The user supplies the cumulant generating function ``K`` as an ordinary Julia function. Every
derivative of ``K`` that the expansions need is generated by Taylor-mode automatic
differentiation ([TaylorSeries.jl](https://github.com/JuliaDiff/TaylorSeries.jl)), directly in the
whitened coordinates in which the terms are evaluated, so no derivative formulas have to be
written by hand and no finite differences are used.

## Installation

The repository is private at the moment; install it from its URL:

```julia
using Pkg
Pkg.add(url="https://github.com/s-broda/SaddlepointExpansions.jl")
```

## A first example

``X = (U_0 + U_1, U_0 + U_2)`` with independent unit exponential ``U_i``, the example of Kolassa
and Li (2010), and ``P(X_1 \ge 3, X_2 \ge 3)`` from the mean of ``n = 5`` observations:

```julia
using SaddlepointExpansions

K = CGF(t -> -log(1 - t[1]) - log(1 - t[2]) - log(1 - t[1] - t[2]), 2;
        domain = t -> t[1] < 1 && t[2] < 1 && t[1] + t[2] < 1)
Kn = sample_mean(K, 5)                      # cumulant generating function of the mean of 5 copies

r = tailprob(Kn, [3.0, 3.0]; order=4)
r.F                                         # expansions of orders 1 to 4 of P(X̄₁ ≥ 3, X̄₂ ≥ 3)
r.tau                                       # the saddlepoint
```

The exact value is ``0.02215196``; the four approximations have relative errors ``-3.3\%``,
``-0.04\%``, ``0.01\%`` and ``-1.5\times10^{-6}``.

The same cumulant generating function is in the library as
`sample_mean(exponential_sums_cgf([1 0; 1 1; 0 1]), 5)` or `exponential_sums_cgf([1 0; 1 1; 0 1]; n=5)`.
