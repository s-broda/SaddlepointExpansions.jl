# SaddlepointExpansions.jl

[![CI](https://github.com/s-broda/SaddlepointExpansions.jl/actions/workflows/CI.yml/badge.svg)](https://github.com/s-broda/SaddlepointExpansions.jl/actions/workflows/CI.yml)
[![Documentation](https://img.shields.io/badge/docs-dev-blue.svg)](https://s-broda.github.io/SaddlepointExpansions.jl/dev/)

Saddlepoint expansions of any order for tail probabilities and densities of random vectors,
from the cumulant generating function alone.

The package implements the expansions of Broda and Kan, *Uniform saddlepoint expansions for
multivariate tail probabilities*: the orthant probability `P(X ≥ x)` of a random vector in any
dimension (first-order term: Kolassa 2003), its density, and the density and distribution
function of a ratio, with the univariate expansions of Daniels and of Hauschildt and Robinson as
the one-dimensional case; and those of Bao, Broda and Kan, *Inversion formulas and saddlepoint
expansions for Studentized means*, for the density and distribution function of ``X/\sqrt{Y}``
(`studentized_density`, `studentized_tailprob`, `studentized_quantile`). The expansion of order `M` has relative error `O(n^-M)`, uniformly for
saddlepoints in the closed positive orthant; saddlepoints with negative components are handled
by inclusion-exclusion.

The cumulant generating function is supplied as an ordinary Julia function. All its derivatives
are generated by Taylor-mode automatic differentiation
([TaylorSeries.jl](https://github.com/JuliaDiff/TaylorSeries.jl)), directly in the whitened
coordinates in which the expansions are evaluated.

```julia
using SaddlepointExpansions

# X = (U0 + U1, U0 + U2), U_i independent unit exponentials; the mean of n = 5 observations
K = CGF(t -> -log(1 - t[1]) - log(1 - t[2]) - log(1 - t[1] - t[2]), 2;
        domain = t -> t[1] < 1 && t[2] < 1 && t[1] + t[2] < 1)
Kn = sample_mean(K, 5)

tailprob(Kn, [3.0, 3.0]; order=4).F    # P(X̄₁ ≥ 3, X̄₂ ≥ 3), orders 1 to 4; exact 0.02215196
density(Kn, [3.0, 3.0]; order=4).f     # the joint density
tailprob(Kn, [3.0, 3.0]; lower=true).F # P(X̄₁ ≤ 3, X̄₂ ≤ 3)
```

Everything is generic in the floating-point type: `BigFloat` arguments give variable precision.
A library of cumulant generating functions (normal, gamma, noncentral chi-squared, quadratic
forms in normal variables, Wishart diagonals, sums of exponentials) and transformations
(reflection, marginals, linear combinations, sample means, independent sums) is included, and
the lower-level derivative interface of the replication material of the paper (`spa_bi`,
`spa_mv`, `spa_orthant`, ...) remains available for models with closed-form derivatives.

## Installation

```julia
using Pkg
Pkg.add(url="https://github.com/s-broda/SaddlepointExpansions.jl")
```

Julia 1.10 or later.

## Documentation

The [documentation](https://s-broda.github.io/SaddlepointExpansions.jl/dev/) has a guide, the
library of cumulant generating functions, a summary of the expansions and the API reference.
To build it locally:

```
julia --project=docs -e 'using Pkg; Pkg.develop(PackageSpec(path=pwd())); Pkg.instantiate()'
julia --project=docs docs/make.jl
```

## Tests

```
julia --project=. -e 'using Pkg; Pkg.test()'
```

The tests check the Taylor-mode derivatives against closed forms, the expansions against exact
values and against the MATLAB programs of the paper, and recompute rows of the paper's tables
from the cumulant generating function alone (about two minutes).

## Citation

If you use this package, please cite the paper:

> Broda, S. A. and Kan, R. Uniform saddlepoint expansions for multivariate tail probabilities.

and, for the Studentized-mean functions,

> Bao, Y., Broda, S. A. and Kan, R. Inversion formulas and saddlepoint expansions for Studentized means.

The replication material of the paper (MATLAB, Julia and Python programs for all its tables) is
in a separate repository.
